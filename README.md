# business-data-management
Data-driven analysis to optimize turnaround time and SLA performance for a real-world service center

This project was completed as part of my Business Data Management coursework and focuses on improving operational efficiency for a real-world authorized service center (Prime Infotech, Calicut, Kerala).

The objective was to analyze warranty Return Material Authorization (RMA) data and identify bottlenecks affecting turnaround time (TAT), SLA compliance, and technician utilization.

The study uses ~1000 real service cases collected over 11 months.

## 🎯 Business Problem
Service centers faced:
- High turnaround times
- SLA breaches
- Repair-stage delays
- Seasonal workload fluctuations
- Idle technician capacity during off-season

## 🛠 Tools & Technologies
- Python (pandas, matplotlib)
- Excel (pivot tables, descriptive stats, correlation analysis)
- Data cleaning & preprocessing
- Statistical analysis
- Visualization

## ✅ Recommendations
- Early escalation for repair delays
- Day-10 watchlist for stuck cases
- Repair fast-track policies
- Schedule AMCs/retail work during off-season
- Diversify services to stabilize revenue
